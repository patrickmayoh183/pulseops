# PulseOps 验收方案与证据

状态：已完成生产部署与基础业务验收，逐项记录如下。下面的“预期”是通过标准，只有状态列和实际验证记录中明确注明的项目才代表已经执行；没有命令输出、测试报告或实际访问证据的项目统一记为未验证。

## 1. 验收记录规则

每次记录应包含：日期、环境、操作或命令、实际结果、必要的截图/日志位置。证据中不能包含密码、完整 Cookie、CSRF 令牌、数据库凭证或云访问密钥。

“构建通过”“单元测试通过”“本地集成通过”“公网验收通过”是不同结论。前端构建成功不能代替页面功能验收，API 能连接不能代替真实数据持久化，部署命令执行完成不能代替公网访问。
